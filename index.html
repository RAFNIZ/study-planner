Tentang Study Planner

Study Planner adalah aplikasi web manajemen tugas kuliah dan produktivitas yang dirancang untuk membantu mahasiswa mengelola jadwal secara efektif. Project ini dikembangkan menggunakan HTML5, CSS3, dan Vanilla JavaScript tanpa bantuan framework eksternal.
